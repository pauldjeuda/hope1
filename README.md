# HOPE Bridge for the Needy

Site de l’association humanitaire HOPE Bridge for the Needy (Yaoundé, Cameroun).  
Design inspiré de la base visuelle Shu Anta (React + Vite + Tailwind).

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir https://localhost:5173

## Contenu

Textes issus du document *Quelques donnees pour site web.docx*, dans `src/i18n/fr.ts` et `src/i18n/en.ts`.
